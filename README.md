# مسجد مبارك — منظومة تحفيظ القرآن الكريم

تطبيق ويب عربي لمتابعة الطلاب والتسميع والحضور والخطط الأسبوعية. تسجيل الدخول يتم عبر **Firebase Authentication**، بينما المشاريع والأعضاء وطلبات الانضمام ومزامنة بيانات كل مشروع تُخزّن في **Firebase Realtime Database**.

## إعداد Firebase (مرة واحدة من مالك المشروع)

التطبيق مضبوط على مشروع Firebase الموجود في `index.html` (`mubarak-79bc1`). لا ترسل كلمات مرور أو مفاتيح Admin في المحادثة؛ إعداد Web API الظاهر في الواجهة ليس مفتاح Admin.

1. من Firebase Console افتح المشروع **mubarak-79bc1**.
2. من **Authentication → Sign-in method** فعّل **Email/Password**.
3. افتح **Realtime Database** وأنشئ قاعدة بيانات إذا لم تكن موجودة. اختَر الموقع المناسب، ثم افتح تبويب **Rules**.
4. احفظ نسخة من القواعد الحالية إذا كانت لديك مسارات أخرى تستخدمها. انشر محتوى الملف [`database.rules.json`](./database.rules.json) في **Realtime Database → Rules** (وليس Firestore)، ثم اضغط **Publish**.
5. افتح التطبيق، أنشئ حساباً وأكّد البريد الإلكتروني. بعد ذلك أنشئ مشروعاً وانسخ كوده أو رابط الدعوة للمشاركين.

## طريقة الاستخدام

- كل مستخدم ينشئ حساباً ببريده وكلمة مرور لا تقل عن 6 أحرف، ثم يؤكد بريده من رسالة التحقق.
- من شاشة المشاريع يمكنه إنشاء مشروع جديد أو إدخال كود/رابط مشروع وطلب الانضمام.
- طلب الانضمام لا يمنح أي صلاحية. يظهر لصاحب المشروع؛ عند القبول يصبح الحساب عضواً وتظهر له البيانات. الرفض لا يتيح الدخول، ويمكن إرسال طلب جديد لاحقاً.
- يستطيع الحساب إنشاء أكثر من مشروع. لكل مشروع بياناته وأعضاؤه المستقلون. يمكن بدء المشروع فارغاً أو نسخ البيانات الموجودة على الجهاز.
- كل عضو مقبول يستطيع تعديل بيانات المشروع، ومالك المشروع وحده يدير طلبات الانضمام.
- يحاول التطبيق نقل النسخة القديمة من `mubarak_app_data/{uid}` إلى مشروع شخصي عند أول دخول. لا تحذف بيانات المسار القديم قبل التأكد من ظهور البيانات المنقولة.

## ملاحظات

- `database.rules.json` يحمي بيانات المشاريع ويترك مسار البيانات القديمة متاحاً لصاحب الحساب فقط لأجل الترحيل.
- إذا كانت قاعدة Realtime Database تحتوي مسارات أخرى لتطبيقات أو خدمات، ادمج قواعدها مع الملف قبل النشر بدلاً من استبدالها عشوائياً.
- عند ظهور خطأ صلاحيات، تأكد من نشر القواعد في **Realtime Database → Rules** في مشروع `mubarak-79bc1`.
